# Triage labels

技能引用分流角色时，应用对应的 GitHub 标签。

| 分流角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已明确，可交给代理实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 维护者已决定关闭请求 |

仓库改用其他标签时，更新 GitHub 标签列。
